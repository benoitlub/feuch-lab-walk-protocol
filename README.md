# FEUCH LAB INSTITUTE — Dr. Marty's Walk Protocol v0.1

**FLI-MW-06 — Experimental Dimensional Locomotion System**

Mobile-first experimental PWA inspired by the abandoned US patent application US20060014125A1 ("Walking Through Walls Training System").

The app deliberately separates three layers:

1. **Historical patent claim** — what the document actually claimed.
2. **Measured reality** — cadence and motion data available from the phone.
3. **Blacklace fiction** — Feuch Level, Reality Adhesion and Vortex Monitor are fictional indicators.

## Safety

This project never instructs the user to walk into, through, or toward a wall, door, furniture, stairs, traffic, or any other obstacle. Guided walking must be performed only in a clear open area and can be stopped at any time.

## Stack

- React
- TypeScript
- Browser motion/orientation APIs when available
- localStorage for experiments
